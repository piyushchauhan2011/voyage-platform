Phase 7

Inventory, bookings, cancellations, and notifications in one place

Use the same JWT-secured APIs your tests exercise, but from a single UI that can seed inventory, create bookings, cancel them, and watch notifications and stock levels update. When application.jobs.async-notifications is on, confirmations ride RabbitMQ — watch them on /ui/jobs.

What this page proves

  • Create inventory as an admin.
  • Create bookings as a user.
  • Cancel bookings and return rooms to inventory.
  • Observe after-commit notifications for both confirmation and cancellation.

Auth helper

Login with any existing user, then reuse the bearer token for all booking and notification calls.

Inventory console

Admin-only writes against /api/v1/inventory.

Booking flow

User-facing create and cancel actions against /api/v1/bookings.

Notifications

After-commit messages for confirmation and cancellation.
