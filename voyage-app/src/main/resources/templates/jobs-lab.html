Scheduler, queues, and delayed jobs

Laravel-style background work inside voyage-app: Redis holds delayed jobs (ZSET), @Scheduled moves due work to RabbitMQ, and workers write notifications / job history. Compare routing on /ui/rabbitmq and booking flow on /ui/bookings.

Suggested path

  1. Login as ADMIN (JWT for actions).
  2. Enqueue an immediate email.send job.
  3. Enqueue a delayed job (5s) and watch the Redis panel.
  4. Refresh runs after the poller publishes to RabbitMQ.
  5. Create a booking — notification arrives via the worker when async is on.
